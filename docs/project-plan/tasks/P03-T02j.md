# P03-T02j — Private guarded credential and MFA adapters

**Status:** [PostgreSQL CI 39922270205](https://github.com/vishweshgawas06-dotcom/fairmount-games/actions/runs/39922270205) passed (2026-10-23). No public login/logout, cookie or MFA endpoint.

`identity/guarded_issuance.py` wraps the existing owner password+MFA issuer, agent/player password issuer, and owner MFA step-up with the P03-T02i transaction-serialized HMAC throttle and failure audit. The public request edge must call **only** these adapters, with a separately held restricted authentication HMAC key and a verified transport peer IP. Both success and generic denial need a caller-owned committed transaction; a callback denial rolls back its SAVEPOINT while the pseudonymous failure and counters commit. Throttling prevents password/MFA proof from running. Unexpected database/key problems propagate instead of being counted as bad credentials. Result objects redact raw session tokens from `repr`.

PostgreSQL integration tests exercise five wrong agent passwords, correct password blocked across a different IP, no session or success audit on blocked/failed attempts, DB-clock window restart, then correct login and live session/success audit. The standalone P03-T02i tests cover unknown subjects, cross-source controls and audit immutability. Owner factor/recovery-code endpoint tests, reverse-proxy origin contract, concurrent worker races, D-02 retention and user-facing denial/CSRF remain open. Raw issuer functions remain internal for setup/testing; routes must never invoke them directly.
