# P03-T01g — Permanent-password policy guard

**Status:** Implemented; Python 3.12 CI pending.

**Authorization:** Owner approved [D-13](../decisions/2026-10-16-password-policy.md) 12–128-character Unicode passphrases for all roles without composition rules, a small local obvious-password block, and rate limits in future endpoints. The owner also clarified in [D-12](../decisions/2026-10-16-owner-bootstrap-and-agent-id-lifecycle.md) that the owner personally runs the local bootstrap command. This slice validates only new permanent passwords.

## Implementation

- `validate_new_password` enforces 12–128 Unicode code points, printable/non-whitespace-only input, valid UTF-8 and a small versioned set of obvious passwords (plus repeated-single-character values). It returns the exact original password: no normalization, trim or case folding before hashing. Weak-list comparison alone uses a stripped casefolded copy.
- `hash_password` calls the validator before Argon2id hashing; verification still accepts the exact supplied password to avoid applying a new policy retroactively to existing hashes. No password is logged or stored in plaintext.
- Unit tests cover length boundaries, passphrases/spaces/Unicode, obvious values, control characters, no implicit trimming and the hash/verify integration. The local weak list is **not** compromised-password screening, and rate limits do not exist yet.
