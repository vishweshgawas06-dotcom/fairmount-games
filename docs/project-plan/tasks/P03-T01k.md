# P03-T01k — Owner-bound TOTP encryption primitive

**Status:** Implemented; Python 3.12 CI pending.

**Authorization:** Owner selected [D-15](../decisions/2026-10-16-owner-mfa-key-custody.md): a deployment-owned key outside DB and Git with a protected offline backup. This pure helper accepts a key supplied by a later trusted key loader. It does not create/store a key, persist a TOTP seed, enroll MFA or authorize access.

## Implementation

- Add `cryptography` runtime dependency. AES-256-GCM encrypts the 160-bit Base32 TOTP seed with a fresh 96-bit nonce. Authenticated associated data binds the encrypted seed to the unique owner account UUID and a positive key version; output contains only version, nonce and ciphertext. Wrong owner, key/version, tampering or malformed data fails closed. No default key or environment fallback exists.
- Unit tests cover round-trip, nonce uniqueness, wrong account/key/version, altered ciphertext/nonce and invalid inputs. A later PostgreSQL MFA schema must store ciphertext/version/nonce, a last-accepted TOTP step and hashed recovery codes; a future key loader, enrollment service and operational backup/rotation runbook remain security gates.
