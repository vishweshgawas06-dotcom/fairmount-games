# P03-T02p — gameplay-write request contract

Status: **implemented and tested; consumed by the opt-in [P11-T03a](P11-T03a.md) bet route.**

## Scope

Adds `fairmount_api/identity/write_boundary.py` and
[the contract note](../auth/GAMEPLAY_WRITE_CONTRACT.md): one reusable guard for
the *shape* of a future gameplay write (bet, rebet, transfer, settlement
confirmation) before any handler parses it.

Implemented checks: `POST` only; the existing same-origin session boundary
(exact HTTPS `Origin`/`Host`, single session cookie, double-submit CSRF); no
query string; JSON-only media type; single bounded `Content-Length` (≤ 4096
bytes, streamed length must match); no `Transfer-Encoding`/`Content-Encoding`;
`Sec-Fetch-Site` may only deny; one normalized non-zero UUID
`Idempotency-Key`; and one JSON object without duplicate keys or
`NaN`/`Infinity`. Every denial raises `GameplayWriteUnavailable` with a generic
message.

Not in scope: any write route, body schema, idempotency persistence, rate
limiting, proxy trust, or gameplay policy.

## Tests

- `tests/test_gameplay_write_boundary.py` (pure): media-type acceptance/rejection,
  ambiguous and duplicate headers, query strings, non-`POST` methods,
  idempotency-key normalization, declared-versus-streamed length mismatch,
  oversized declared and streamed bodies, invalid size limits, malformed JSON,
  duplicate JSON keys and non-finite numbers.
- `tests/test_gameplay_write_boundary.py` (HTTP, test-only probe app): a valid
  same-origin JSON write passes with `Cache-Control: no-store`; form, `text/plain`,
  missing CSRF and wrong origin are denied; denial bodies leak no token or cookie.
  The probe app is defined in the test module and is **not** mounted by
  `fairmount_api.main`.
- `tests/test_gameplay_write_boundary.py` (PostgreSQL, DB-gated): a real
  `issue_member_session` PLAYER token passes the envelope, then resolves to the
  expected account; revocation after the envelope makes `resolve_session()`
  return `None`. A forged token neither resolves nor revokes. This is the
  evidence that the envelope is not authorization.
