# P03-T01e — Fixed V1 Agent IDs

**Status:** Implemented; PostgreSQL CI verification pending.

**Authorization:** Owner approved fixed Agent IDs and trusted local owner bootstrap as [D-12](../decisions/2026-10-16-owner-bootstrap-and-agent-id-lifecycle.md). This bounded slice enforces **only** the already-approved Agent-ID lifecycle rule. Bootstrap credentials/MFA are not implemented here.

## Implementation

- Alembic revision `20261016_05` adds a PostgreSQL trigger that prevents updates to account ID, login kind or Agent ID after initial assignment, and prevents deletion of an assigned agent identity. The earlier player trigger remains independent. Pre-activation null → valid generated Agent-ID assignment and profile updates remain possible.
- The trigger does not decide anonymization, old ID reuse, retention, or owner recovery; D-02/D-11 and D-03 remain open. No Agent-ID editing or deletion/reuse endpoint is added. A future approved privacy lifecycle may require a reviewed migration of this guard.
