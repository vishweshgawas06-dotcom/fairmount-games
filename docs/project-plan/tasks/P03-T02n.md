# P03-T02n — Opt-in direct-TLS guarded login HTTP boundary

**Status:** Local Ruff/unittest passed; Python 3.12/PostgreSQL CI pending. Disabled in the HTTP preview by default; **not approved for reverse-proxy deployment**.

`POST /api/v1/auth/login` accepts bounded JSON for an already-activated OWNER (password and TOTP/recovery proof) or AGENT/PLAYER (role-bound fixed ID and password). It requires explicit `FAIRMOUNT_AUTH_EDGE_MODE=direct-tls`, one canonical `FAIRMOUNT_PUBLIC_ORIGIN=https://...`, an actual ASGI HTTPS connection to a directly connected IP peer, exact Host/Origin and **no forwarding headers**. No proxy IP is silently taken from `X-Forwarded-For`. It fails closed in the present port-8000 HTTP preview. Operators must disable ASGI proxy-header trust and terminate TLS **at the API** before considering opt-in; forwarded/reverse-proxy topology requires separate security design and tests.

The route requires a migrated PostgreSQL API URL, a restricted separately provisioned auth-HMAC key file and, for OWNER, the independent MFA keyring. It calls the existing serialized guarded issuers and commits both generic denials/throttle audits and successful session issuance **before** setting Secure/HttpOnly/Strict host-only session and separate CSRF cookies. It returns neither credentials, MFA proofs nor bearer tokens in JSON. Denial/throttle look identical. Malformed, oversize and duplicate-field requests are rejected before proof; transport/configuration/DB failures do not reveal secrets. Owner provisioning and MFA enrollment remain owner-operated local/private services, never offered as public setup endpoints.

HTTP tests cover disabled-by-default/no HTTP bypass, cross-site/forwarded/unknown peer denial, malformed JSON, generic failures, owner MFA dispatch and post-transaction cookie behavior. Private guarded issuance and DB-backed throttle have their own PostgreSQL tests, but this slice **does not** yet test a real committed full HTTP login→protected resource→logout sequence. No publicly authorized wallet/bet/gameplay mutation route, reverse-proxy contract, D-02 retention policy or production readiness is claimed. Never enable `direct-tls` behind the Arena preview proxy.
