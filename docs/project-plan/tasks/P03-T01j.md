# P03-T01j — Pure owner MFA primitives

**Status:** Implemented; Python 3.12 CI pending.

**Authorization:** D-03 owner TOTP plus one-time offline recovery codes and the owner's broad staged implementation permission. This slice adds pure generation/verification helpers and tests only; no factor enrollment, storage, dashboard, session, or recovery API.

## Implementation and boundaries

- Generate a 160-bit Base32 TOTP seed and RFC 6238 SHA-1/6-digit/30-second codes. Accept at most one 30-second step of drift either side; return the **matched step**, not an access decision, so the future locked transaction can reject any step already accepted and prevent replay.
- Generate ten distinct 16-character uppercase recovery codes from a 32-character unambiguous alphabet (80 bits per code). Hash only canonical codes with SHA-256, appropriate for random codes; verify using constant-time digest comparison. Future storage must keep only digests and consume each code atomically; **this helper does not make codes single-use**.
- Unit tests include RFC 6238 SHA-1 vectors, drift/out-of-window/invalid input, distinct generated codes, case-insensitive/hyphenated recovery-code input and malformed/confusable input. Secrets must never be logged. TOTP secret encryption, key custody, recovery-code persistence and audit are later gates.
