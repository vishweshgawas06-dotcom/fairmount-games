# P11-T01d — Cross-round reserve isolation test

**Status:** [PostgreSQL CI 39915956422](https://github.com/vishweshgawas06-dotcom/fairmount-games/actions/runs/39915956422) passed (2026-10-23). Test-only checkpoint; no public worker/route.

`test_two_unsettled_rounds_share_liability_and_release_only_finished_round` holds a 350-point obligation on a CLOSED first round and tries to admit a matching 350-point obligation on a new OPEN round. The second bet is rejected while the global reserve would have only 360. A separate owner-funded 340-point deposit then makes the second stake admissible at exactly 700 reserve points for 700 in joint worst-case payout. Paying the first winning round reduces reserve to 350 but leaves the second OPEN. A test-only trusted void refunds the second accepted 10-point stake and leaves 340 in reserve; the journal and issuance still reconcile. This ensures settling one round cannot erase another round's obligations or drain money already owed to it.

This sequential multi-round test does not prove a concurrent settlement/admission interleaving, process crash recovery, withdrawal solvency or production void authorization. D-06 remains an open decision. The fixture uses the documented privileged, guard-restored time warp only in tests.
