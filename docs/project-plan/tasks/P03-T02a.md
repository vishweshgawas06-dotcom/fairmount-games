## Implementation

- Alembic revision `20261019_01` adds `account_sessions` with account/role composite FK, globally unique lowercase token digest, timestamp checks and a partial unique index on unrevoked `account_id`. Each role's exact idle/absolute deadline is constrained by the approved policy; OWNER requires an MFA timestamp, AGENT/PLAYER forbid it. No raw bearer token or cookie is stored.
- PostgreSQL tests cover valid role-specific rows, duplicate active sessions, revocation then new session, duplicate digests, bad expiry/role/MFA shapes and role-update refusal. A session row alone cannot authenticate or authorize anyone.
