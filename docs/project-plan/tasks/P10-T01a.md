`apps/player-web/preview/` contains an original responsive dark-green roulette viewing layout, built without external image/font/CDN dependencies. On this repository checkout the API serves it at `/preview/` and redirects `/` there. It polls the same-origin `/api/v1/roulette/round` snapshot and shows only persisted, server-revealed numbers and prior revealed results. The illustrative 37-pocket wheel follows the authentic single-zero European order; the ball and result are hidden before the server-revealed `RESULT` phase. Decorative alignment uses the server result only, never a browser RNG or bets/stakes. The number layout is **non-interactive** and the UI explicitly says login, wagers, point transfers and balances are unavailable. An unavailable database displays a truthful disconnected state, never mock outcomes; polling backs off to 30 seconds while unavailable and resets after recovery.

Pure Node tests verify all 37 unique pockets, color mapping, pre-reveal gating and alignment for every possible result. API tests verify static assets/preview routing and a generic missing-database response. This does **not** satisfy P10 gameplay, P12 realism/physics/smoothness, accessibility/device sign-off, P14 responsive acceptance or D-09 owner visual approval. The shell is only hosted when the frontend directory is present; production UI deployment is a separate gate.
