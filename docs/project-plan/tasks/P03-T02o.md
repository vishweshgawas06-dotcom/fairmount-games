# P03-T02o — Direct-TLS CSRF-guarded browser logout

**Status:** Local tests and [CI 40092369410](https://github.com/vishweshgawas06-dotcom/fairmount-games/actions/runs/40092369410) passed (Python 3.12/PostgreSQL + Node). Disabled behind this preview proxy.

`POST /api/v1/auth/logout` reuses P03-T02n's explicit direct-TLS, exact Host/Origin and verified transport-peer gate. It requires exactly one well-formed `__Host-fairmount_session` cookie, one `__Host-fairmount_csrf` cookie and matching `X-CSRF-Token`; duplicate cookies, missing/mismatched CSRF and cross-site requests are denied. It checks the migrated database and runs the private bearer-possession revocation/audit in a transaction. **Only after commit** does the response clear both cookies. Unknown/already-revoked sessions are acknowledged identically without exposing account state. A database failure does not clear cookies or claim a successful logout; it returns a generic no-store 503. No forwarded client identity is trusted.

HTTP tests verify fail-closed preview/HTTP, CSRF/origin/cookie ambiguity, idempotent revocation, cookie clearing and DB-error handling. Existing PostgreSQL tests cover actual session revocation, audit and rollback; a real full login→protected resource→logout request sequence remains a separate gate. Proxy trust, authorized resource and gameplay routes, refresh/session lifetime UX and D-02 retention are still open. This is not production authentication approval.
