# P01-T01 — Establish the Python API foundation

**Status:** Initial implementation committed; local verification pending  
**Phase:** P01 — Repository foundation  
**Priority:** Required before database or gameplay implementation

## Scope

- Add root Python project metadata and development dependencies.
- Create the importable FastAPI application under `services/api/src/fairmount_api/`.
- Add a liveness-only endpoint at `GET /health/live`.
- Add smoke tests and a GitHub Actions workflow that installs dependencies, runs the full unittest suite, and runs Ruff.
- Document how to install, run, and test the API locally.

## Explicit boundaries

- This is a repository/bootstrap task, not a betting engine.
- The liveness endpoint does not claim that PostgreSQL, Redis, authentication, or gameplay services are ready.
- No wallet, bet acceptance, round, payout, settlement, or real-money routes are implemented.
- No secrets belong in source control.

## Acceptance criteria

1. A Python 3.12 environment can install the project using `python -m pip install -e ".[dev]"`.
2. `python -m unittest discover -s tests -v` runs catalogue and API smoke tests.
3. `ruff check .` passes.
4. `uvicorn fairmount_api.main:app --reload --app-dir services/api/src` starts the local API.
5. `GET http://127.0.0.1:8000/health/live` returns HTTP 200 and `{"status":"ok","service":"fairmount-api"}`.
6. CI executes the same test and lint commands.
7. No gameplay behavior is represented as implemented.
