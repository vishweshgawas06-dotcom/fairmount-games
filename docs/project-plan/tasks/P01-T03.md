# P01-T03 — Reproducible local PostgreSQL test environment

**Status:** Implementation prepared; verification pending GitHub CI Compose run.

**Authorization:** Owner approved P01-T03 on 2026-10-16. Scope is local PostgreSQL infrastructure and connection check only; no domain schema, migrations, API database readiness route, wallet/betting logic or deployment.

## Deliverables

- Localhost-only PostgreSQL 16 Docker Compose service with a health check and persistent named *local* volume.
- Safe `.env.example` variable names/placeholder values; `.env` is ignored. Isolated `fairmount_dev` and `fairmount_test` databases; Python check creates the test database if absent and verifies an actual connection without dropping any database.
- Python 3.12/3.13 development dependency on Psycopg and dotenv; documented clean-clone startup/teardown for Unix shells and Windows PowerShell.
- CI starts the same Compose file on a clean checkout, runs the connection check, existing tests and Ruff, and always attempts to remove the ephemeral CI volume.

## Acceptance / verification gate

- [x] Compose file, safe local configuration, no committed secrets or game schema.
- [x] Check script refuses non-local/non-project DB names and verifies connection to distinct test DB. This is a code/config review claim, not yet a PostgreSQL execution claim.
- [x] README documents supported Python, Docker commands, credentials, preserving versus deleting volume and isolation.
- [ ] GitHub runner starts Compose, Python connects to `fairmount_test`, unittest and Ruff pass, and CI tears down. Record run URL and results.
- [ ] Record local Docker availability and any limitations accurately; only call P01-T03 complete when actual Compose/test connection evidence is recorded.

## Known limitations

The API is still liveness-only. The database connection check is an infrastructure smoke check, not an API database-readiness endpoint. No SQLAlchemy models, Alembic migrations, accounting operations, or transaction/concurrency tests exist. Later database tasks need separate approval and a supported PostgreSQL test environment.
